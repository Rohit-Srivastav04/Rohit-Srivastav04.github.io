# We Can Do Devil — GitHub Pages (privacy + app-ads.txt)

Haan — **apni alag paid website ki zarurat nahi**.  
`rohitkal.github.io` pe free host karke Play Console + AdMob dono chal jayenge.

## Final URLs (repo publish ke baad)

- Home: `https://rohitkal.github.io/`
- Privacy (Play Console): `https://rohitkal.github.io/privacy.html`
- AdMob app-ads.txt: `https://rohitkal.github.io/app-ads.txt`

## Setup steps (GitHub)

1. GitHub pe login → **New repository**
2. Repository name **exactly**: `rohitkal.github.io`  
   (username `rohitkal` hona chahiye — warna `USERNAME.github.io` use karo)
3. Public repo banao
4. Is folder ki files upload karo (root pe):
   - `index.html`
   - `privacy.html`
   - `app-ads.txt`
   - `icon-512.png`
5. Repo → **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` (root `/`)
6. 1–2 minute wait → URLs open karke check karo
